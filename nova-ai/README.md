# NOVA_AI Landing Page

موقع NOVA_AI التسويقي للذكاء الاصطناعي مع فيديو خلفية متزامن مع حركة التمرير (Scroll-Scrubbed Video) وتأثير الزجاج المفرغ ورقاقات تفاعلية.

## طريقة التشغيل:

1. افتح موجه الأوامر (Terminal / CMD) في هذا المجلد:
```bash
npm install
npm run dev
```

2. افتح الرابط في المتصفح:
`http://localhost:5173`
