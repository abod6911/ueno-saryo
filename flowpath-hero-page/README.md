# Flowpath Hero Page

قسم رئيسي (Hero Section) لتطبيق SaaS "Flowpath" بتصميم عصري وخلفية فيديو وتأثير Liquid Glass مع قوائم منسدلة تفاعلية.

## طريقة التشغيل:

1. افتح موجه الأوامر (Terminal / CMD) في هذا المجلد:
```bash
npm install
npm run dev
```

2. افتح الرابط في المتصفح:
`http://localhost:5173`
